## 📁 文件命名规范

统一格式：`[发表年份]-[第一作者]-[核心主题]-[研究类型].pdf`

- 研究类型：`Theory`（理论）、`CaseStudy`（案例研究）、`Monograph`（专著）等。

示例：
- `2025-何国瑞-智质心理学-Theory.pdf`
- `2025-GuoruiHe-NoeticPsychology-Theory.pdf`
- `2025-何国瑞-石头不是工具-CaseStudy.pdf`
