## 📁 文件命名规范

为保持目录整洁与可追溯性，本文件夹所有文件统一遵循：

```
[发表年份]-[第一作者]-[核心主题关键词]-[研究类型].[扩展名]
```

**示例**：
- `2026-何国瑞-从概率机到公理机-Prediction.pdf`
- `2026-GuoruiHe-ProbabilisticToAxiomatic-Prediction.pdf`

**研究类型标识**：
- `Prediction`：理论预测类论文
- `Analysis`：机制分析类论文
- `Framework`：理论框架类论文
