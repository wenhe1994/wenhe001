# 系统本体论与智质生态学

## 概述

本仓库确立了"智质生态学"、"系统本体论"和“文明动力学”理论体系的核心框架。该体系通过三个层级的一系列公理、定理集和理论模型，构建了一个解释从个体认知到文明演化的统一框架。
